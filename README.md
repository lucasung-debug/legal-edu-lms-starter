# 법정필수교육 LMS

직원이 로그인해 법정필수교육 영상을 **빨리감기 없이** 시청하면 이수가 기록되고, HR은 이수율 확인·독촉 메일·대표이사 명의 수료증까지 한곳에서 관리합니다.

개발 지식이 없어도 쓸 수 있도록 만들었고, 외부 프로그램은 Node.js 하나만 필요합니다. 교육 영상은 들어 있지 않으며 회사에서 직접 넣습니다.

## 5분 시작

1. [Node.js](https://nodejs.org/ko/download) LTS 버전을 설치합니다. (22.13 이상)
2. 이 폴더의 **`시작하기.bat`** 을 더블클릭합니다. macOS는 `시작하기.command` 입니다.
3. 브라우저에 설정 화면이 열리면 회사명, 대표이사 성명, 관리자 비밀번호를 입력합니다.
4. **시작하기** 화면의 순서대로 따라갑니다.

| 순서 | 할 일 | 어디서 |
|---|---|---|
| 1 | 회사 정보 확인 | 설정 |
| 2 | 교육 과정 만들기: 템플릿을 고르고 유튜브 링크나 MP4 파일을 넣기 | 교육 과정 |
| 3 | 교육생 명부 올리기: 엑셀 양식에 이름·이메일·휴대폰 채우기 | 교육생 명부 |
| 4 | 메일 연결 (선택) | 설정 |
| 5 | 안내문을 복사해 직원에게 보내기 | 시작하기 |

처음이라면 설정 3단계에서 **샘플로 먼저 둘러보기** 를 고르세요. 가상의 교육생과 공개 영상으로 전체 기능을 볼 수 있고, 버튼 하나로 지워집니다.

## 계정

| 구분 | 아이디 | 비밀번호 |
|---|---|---|
| HR 관리자 | `admin` | 처음 설정할 때 정한 비밀번호 |
| 교육생 | 이메일의 @ 앞부분 | 처음에는 휴대폰 번호 뒤 4자리, 첫 로그인 때 본인이 변경 |

관리자 계정은 관리 전용이라 수강할 수 없습니다. HR 담당자와 대표이사도 교육 대상이면 교육생으로 명부에 넣어 주세요.

## 주요 기능

- **빨리감기 방지**: 시청하지 않은 구간으로 이동할 수 없고, 1배속으로만 재생됩니다. 진도는 서버가 실제 경과 시간으로 다시 계산합니다.
- **교육 기간**: 시작일 전 수강 불가, 마감 후 12/31까지 지연 이수 인정, 이후 미이수 확정.
- **독촉**: 마감 10·5·3·1일 전 자동 메일, 마감 후 매주 독촉 (일정은 설정에서 변경).
- **수료증**: 대표이사 명의로 자동 발급, 인쇄·PDF 저장, 재발급·효력정지.
- **기록**: 영상 교체·삭제 이력, 이수 현황 엑셀(CSV) 다운로드.
- **연도별 명부 교체**: 새 명부를 올리면 신규·변경·퇴사자를 미리 보여 주고 지난 기록은 보존합니다.

시청 중 다른 탭으로 옮기거나 창을 내려도 재생과 기록은 계속됩니다.

## 직원이 접속하려면

이 프로그램은 **실행한 PC가 곧 서버**입니다. PC가 꺼지거나 실행 창을 닫으면 접속이 끊깁니다.

| 상황 | 방법 |
|---|---|
| 혼자 살펴보기 | `http://localhost:3000` |
| 같은 사무실 네트워크 | 실행 창과 시작하기 화면에 나오는 주소. 안 열리면 Windows 방화벽에서 3000번 포트를 허용해야 합니다. |
| 실제 전 직원 운영 | 상시 켜 둔 PC나 서버, 회사 주소가 필요합니다. IT 담당자와 상의하세요. |

실제 운영 주소가 정해지면 **설정 > 직원 접속 주소** 에 넣어 주세요. 독촉 메일의 교육 바로가기에 들어갑니다.

## 알아 두실 점

- **법령 확인**: 과정 템플릿의 법령과 안내는 참고용입니다. 교육 시간·대상·내용 기준은 회사 상황에 맞게 담당 기관이나 노무사에게 확인하세요.
- **필수 내용**: 성희롱 예방교육은 고용노동부 공통 영상 외에 회사 자체의 처리 절차·고충상담 교육이 추가로 필요합니다. 템플릿으로 과정을 만들 때 안내가 나옵니다.
- **영상 이용 조건**: 공공기관 교육 영상도 출처 표시나 제3자 제공 금지 같은 조건이 있을 수 있습니다. 받은 곳의 안내를 확인하고 **출처 표시** 칸에 적어 주세요.
- **초기 비밀번호**: 휴대폰 뒤 4자리는 동료가 알 수 있는 값입니다. 명부를 올린 뒤 바로 각자 비밀번호를 바꾸도록 안내하세요. 인터넷에 공개된 주소로 운영한다면 특히 중요합니다.
- **HTTPS**: 회사 밖에서 접속하게 하려면 HTTPS 주소로 운영하세요.
- **백업**: 이수 기록과 명부는 `data` 폴더, 올린 영상은 `public/videos` 폴더에 있습니다. 법정교육 증빙으로 쓰려면 정기적으로 백업하세요.
- **비밀번호를 잊었을 때**: 교육생은 관리자 화면에서 초기화할 수 있습니다. 관리자 비밀번호는 되찾을 수 없습니다.

## 메일 연결 (Gmail·구글 워크스페이스)

1. 구글 계정에서 2단계 인증을 켭니다.
2. [앱 비밀번호](https://myaccount.google.com/apppasswords) 를 만듭니다. (16자리)
3. **설정 > 메일 연결** 에 계정과 앱 비밀번호를 넣고 저장합니다.
4. **테스트 메일 보내기** 로 확인합니다.

비밀번호는 이 PC의 `.env` 파일에만 저장됩니다. 폴더를 다른 사람에게 줄 때는 `.env` 와 `data` 폴더를 빼 주세요.

## 자주 묻는 질문

**압축 파일 안에서 바로 실행이 안 돼요.** 먼저 압축을 풀어 주세요. Windows 보호 창이 뜨면 "추가 정보 > 실행"을 눌러야 할 수 있습니다.

**실행했는데 창이 바로 닫혀요.** Node.js가 없거나 오래된 버전일 수 있습니다. 설치 후 다시 실행하세요.

**"포트를 이미 쓰고 있습니다"라고 나와요.** 이미 켜져 있습니다. 브라우저에서 `http://localhost:3000` 을 여세요.

**유튜브 영상이 재생되지 않아요.** 영상 소유자가 퍼가기를 막았거나 회사 네트워크에서 유튜브가 차단되었을 수 있습니다.

**처음부터 다시 시작하고 싶어요.** LMS를 끄고 `data` 폴더를 지운 뒤 다시 실행하세요. 모든 기록이 사라지니 먼저 백업하세요.
